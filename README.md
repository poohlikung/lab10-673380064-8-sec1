<h1>นายสรวิชญ์ วันเสน</h1>
<h2>รหัสนักศึกษา 673380064-8 SEC.1</h2>
<h2>รายงานผลการทดลองอยู่ในโฟลเดอร์</h2>

## Endpoints
- `GET /products` — แสดงสินค้าทั้งหมด
- `GET /products/{id}` — ค้นหาสินค้าตาม ID
- `POST /products` — เพิ่มสินค้าใหม่
- `DELETE /products/{id}` — ลบสินค้าตาม ID
- `GET /products/category/{category}` — ค้นหาสินค้าตามหมวดหมู่
- `GET /products/{id}/price` — แสดงราคาสินค้าหลังหักส่วนลด
